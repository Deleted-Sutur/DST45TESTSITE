Ресурсы для веб-дизайнера по типографике

1. Базы знаний и фундаментальные книги

  • «Шрифт и дизайн» — Джеймс Крейг
  • «О шрифте» — Эмиль Рудер
  • «Живая типографика» — Александра Королькова
  • «Вебитика» (Webtypography.net) — Онлайн-руководство по веб-типографике, основанное на книге Ричарда Руттера
  • «Better Web Type» — Онлайн-курс и книга о типографике для веба

2. Каталоги и подборки шрифтов

Бесплатные шрифты:
  • Google Fonts — Самый популярный каталог с открытыми шрифтами, отличной фильтрацией и статистикой.
  • Fontshare — Качественная коллекция бесплатных шрифтов от Indian Type Foundry.
  • Font Squirrel — Подборка бесплатных коммерческих шрифтов хорошего качества.
Платные и премиум-шрифты:
  • Adobe Fonts (ранее Typekit) — Огромная библиотека, интегрированная с подпиской на Creative Cloud.
  • MyFonts — Крупнейший маркетплейс шрифтов от множества студий.
  • Fontspring — Еще один отличный магазин с четкими лицензиями.
  • Future Fonts — Платформа для поддержки developing и экспериментальных шрифтов.
Специализированные ресурсы:
  • v-fonts.com — Каталог исключительно переменных шрифтов с возможностью предпросмотра и настройки осей.
  • Wakamai Fondue — Сервис, который анализирует загруженный вами файл шрифта и показывает, на что он способен (поддержка OpenType-фич, оси переменного шрифта и т.д.).

3. Инструменты для работы и тестирования

Подбор и комбинирование пар шрифтов:
  • Typewolf — Блог с реальными примерами использования шрифтов на сайтах, рекомендациями и подборками.
  • Font Pair — Специализируется на подборе гармоничных пар шрифтов из Google Fonts.
  • Fonts In Use — Архив примеров использования шрифтов в дизайне, печати и вебе.
Тестирование и проверка читаемости:
  • WebAIM Contrast Checker — Лучший инструмент для проверки цветового контраста по стандартам WCAG.
  • Modular Scale — Онлайн-калькулятор для построения модульной шкалы размеров типографики.
  • Golden Ratio Typography Calculator — Калькулятор, помогающий рассчитать идеальную высоту строки и ширину колонки.
Песочницы и генераторы кода:
  • CodePen — Для быстрого прототипирования и экспериментов с CSS-свойствами для текста.
  • Axis-Praxis — Площадка для экспериментов с переменными шрифтами прямо в браузере.
  • CSS Font Stack — Помогает определить, какие «безопасные» шрифты установлены на разных ОС.

4. Производительность и техническая оптимизация

  • Font Style Matcher — Помогает подобрать параметры фолбэк-шрифта, чтобы при загрузке кастомного шрифта с font-display: swap не было резкого скачка (FOUT).
  • Glyphhanger — Командная утилита для создания подмножеств шрифтов (оставляет только нужные символы, например, кириллицу).
  • Transfonter — Онлайн-сервис для конвертации и оптимизации шрифтовых файлов (генерация WOFF/WOFF2).

5. Браузерные инструменты (Developer Tools)

  • Инспектор шрифтов в Chrome DevTools — Показывает все примененные к элементу шрифты, их размер, высоту строки и т.д.
  • Панель «Rendering» в Chrome DevTools — Позволяет включить эмуляцию различных нарушений зрения (дальтонизм) для проверки доступности.
  • Инструмент «Fonts» в Firefox DevTools — Показывает всю информацию о загруженных шрифтах на странице, включая путь, формат, метрики и т.д.

6. Сообщества и блоги для вдохновения

  • Typographic Journal — Публикации о типографике и дизайне.
  • I Love Typography — Один из самых известных блогов о типографике.
  • Typography.Guru — Форум и блог для типографов и дизайнеров.
  • r/typography — Сообщество на Reddit.
